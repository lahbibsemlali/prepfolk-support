# Prepfolk support website

Public static support, privacy and terms pages for Prepfolk. Publisher: Lahbib Semlali. Contact: lahbibdev@gmail.com.

Deployment: GitHub Pages from main/root. This repository contains website files only, no app source, secrets, signing credentials or backend. No JavaScript, analytics, forms or external font requests. Manrope is self-hosted under SIL Open Font License; see fonts/OFL.txt.

App repository maintains the source copy under support-site/. Review changes there, copy this folder to the deployment repository, commit and push. Keep these pages aligned with enabled app functionality and App Store privacy disclosures. Do not upload app assets, .env files, private keys or app source here.
